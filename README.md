# USB

VB6 Media Detect utility (`Media.exe` / `USB.vbp`) that subclasses the main window to watch device-change messages and report USB attach/remove, removable media insert/eject, and network drive map/unmap by drive letter. Distinct from the later VB.NET USB experiments repo. Open `USB.vbp` in the VB6 IDE.

**Source last updated:** 2026-08-27 · **Language:** VB6 · **Target:** VB6 Win32 · **Output:** WinForms exe

## Solution structure

| Project | Language | Type | Purpose |
|---------|----------|------|---------|
| `Media` (`USB.vbp`) | VB6 | WinForms exe | Detect USB/media/network drive arrival and removal |

## How to open

Open the `.vbp` in Visual Basic 6.0 IDE:
- `USB.vbp`
